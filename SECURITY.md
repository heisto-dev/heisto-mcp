# Security policy

Report vulnerabilities privately to support@heisto.xyz. Do not include private
keys, API credentials, personal data or live exploit instructions in public issues.
This module is deliberately read-only. Never add signing, wallet access, attack
submission or Sentinel creation tools to this public endpoint.

Guard is a pattern-based first filter, not an authorization boundary.
The Heisto program is upgradeable and has not been independently audited.
Namespace ownership and reproducible-build verification are not independent audits.
